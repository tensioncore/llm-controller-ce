About LLM Controller

LLM Controller is a local-first dashboard for running and managing Large Language Models on your own hardware.

It lets you launch, switch, and monitor local models with real-time insight into performance and GPU usage.

Built on a configured llama-server runtime, it supports multi-GPU operation and an optional dedicated title-generation model on compatible hosts.
Key Features
  • Model Management: Scan, launch, stop, and switch local models.
  • Live Analytics: Logs, GPU telemetry, token throughput, and latency metrics.
  • Modern Chat UI: Streaming output, Markdown, code, math, and titles.
  • Local Attachments: Document understanding and images with compatible vision models.
  • Projects & Instructions: Organize conversations and save personal or Project Instructions.
